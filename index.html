Case Studies

▸ Case Study

Kost SaaS — Multi-tenant Boarding-House Management

Problem: rent tracking, overdue reminders, tenant self-service via WhatsApp + spreadsheets; high arrears, no audit trail.

Approach: Next.js + Prisma + Neon Postgres; multi-tenant orgs/buildings/rooms/renters; payments + receipts; renter portal; WhatsApp reminder templates; onboarding wizard.

Result: end-to-end rent lifecycle digitized; trial landlords onboarded in <1 day; overdue dashboard reduced manual follow-up.

Stack: Next.js 15, Prisma, Neon Postgres, Tailwind/shadcn, NextAuth.
▸ Case Study

Ternak — Dairy Farm Operations Suite

Problem: no single source of truth for herd health, milking yield, feed inventory; decisions on gut feel.

Approach: full-stack app with herd registry, milking logs, inventory/land & pasture, reports & analytics; E2E-tested; single-farm focus with pilot pricing.

Result: 5 phases shipped (herd → milking → inventory → land → reports); pilot-ready for 3–5 farms.

Stack: Next.js, Prisma, PostgreSQL, Playwright E2E.
▸ Case Study

Resi-tracker — Shipping Tracking API + Web

Problem: manual tracking across couriers; no unified API for internal tools.

Approach: web + REST API with JWT/API-key auth, HMAC signing, rate limits, docs; TIKI scraper live; multi-courier roadmap.

Result: working tracker + documented API; ready for caching/persistence/billing phase.

Stack: Next.js, REST, JWT/API keys, HMAC, rate limiting.
